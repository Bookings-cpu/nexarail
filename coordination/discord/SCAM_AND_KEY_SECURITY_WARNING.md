# SCAM & KEY SECURITY WARNING

Pin this in `#start-here` and `#faucet-requests`. Copy it word-for-word.

---

**READ THIS BEFORE YOU DO ANYTHING**

NexaRail is a testnet. Tokens have no monetary value. Anyone offering to buy, sell, or trade testnet tokens is a scammer.

**The team will never:**

- Ask for your mnemonic, seed phrase, private key, or keyring password
- DM you first with a "support" or "verification" request
- Ask you to connect a wallet to a website to "claim" or "verify" your validator
- Ask you to send any amount of any token to receive testnet funds
- Ask you to install a binary that is not linked from our official GitHub
- Ask you to run a script you can't read

**You should never:**

- Paste your mnemonic anywhere
- Share screenshots that include your terminal during key generation
- Type your mnemonic into an AI tool (ChatGPT, Claude, anything)
- Trust a DM from anyone claiming to be the team
- Trust a `#faucet-requests` reply from anyone but a coordinator/moderator role
- Click an invite link to a "NexaRail" server you did not get from our verified channels

**If someone claims to be the team and asks for any of the above — they are not the team. Screenshot, report, block.**
